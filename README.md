# Video Player & Reels Controls for Facebook™ — Support

Welcome to the public support repository for **Video Player & Reels Controls for Facebook™**.

Use this repository to report bugs, suggest improvements, and ask questions about the extension. This repository contains support information only; the extension’s source code is maintained privately.

## Report a bug

Open the **Issues** tab and select **New issue**.

Please include:

- Extension version
- Chrome version and operating system
- Steps to reproduce the problem
- What you expected to happen
- What actually happened
- Screenshots or error messages, if helpful

For playback problems, mention whether the issue affects a Video or Reel and whether you were using the regular player, mini-player, or Picture-in-Picture.

Please search existing issues before opening a new report.

## Suggest an improvement

Open an issue describing your suggestion, the problem it would solve, and how you would use it.

## Basic troubleshooting

Before reporting a problem:

1. Update Chrome and the extension.
2. Reload the Facebook tab.
3. Check the extension’s settings.
4. If possible, check whether the issue also affects another video you have permission to access.

Some playback features depend on the streams Facebook provides, browser capabilities, and your access to the content.

## Protect your privacy

Issues and comments in this repository are public.

Do not post:

- Passwords, cookies, access tokens, or session information
- Signed video download URLs
- Private Facebook content or personal information
- Unredacted screenshots or logs containing sensitive information

A description of the problem is enough to start. Do not share private content to demonstrate a bug.

## Response times

Support is provided by the developer as time permits. Response times may vary.
